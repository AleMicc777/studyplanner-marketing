# StudyPlanner Marketing Site

Static marketing site for StudyPlanner (AI-powered MSc degree planning tool). Single-page layout with anchor-linked sections plus a standalone contact page.

## Stack

Astro 6 + Tailwind v4.

## Commands

- `npm install` — install dependencies
- `npm run dev` — dev server at `localhost:4321`
- `npm run build` — production build to `./dist/`
- `npm run preview` — preview the production build locally

## Deploy

Vercel — https://studyplanner-marketing.vercel.app

See `AGENTS.md` for file map and conventions.
